  1. Butona basınca GitHub'da önceden doldurulmuş bir denetim talebi açılır → Submit'e basın.
  2. GitHub Actions gerçek bir Chromium ile siteyi 3 senaryoda gezer: onay öncesi, "Kabul et" + ürün/sepet, "Reddet".
  3. ~2–4 dakika sonra talebe rapor linki yorum olarak eklenir (e-posta bildirimi gelir).

Not: Talepler herkese açık bir GitHub deposunda işlenir ve GitHub hesabı gerektirir. Otomatik tarama checkout/purchase adımına giremez; satın alma dahil tam funnel için ② HAR ile derin denetim sekmesini kullanın.

  1. Chrome'da sitenizi açın, DevTools → Network sekmesinde Preserve log'u işaretleyin.
  2. Funnel'ı gezin: kategori → ürün → sepete ekle → checkout → (mümkünse) satın alma.
  3. Network listesine sağ tıklayın → Save all as HAR (çerez kontrolü için "with sensitive data" seçeneği önerilir).
  4. Opsiyonel: yeni gizli pencerede banner'da Reddet'e basıp birkaç sayfa gezin ve bunu ayrı HAR olarak kaydedin.
  5. Opsiyonel: her funnel adımında konsolda aşağıdaki kodu çalıştırıp dataLayer çıktılarını yapıştırın.
